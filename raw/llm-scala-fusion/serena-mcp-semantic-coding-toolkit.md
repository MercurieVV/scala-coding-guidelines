## What Serena is (README, extracted)

Serena delivers essential semantic code retrieval, editing, refactoring and debugging tools operating at the symbol level while exploiting relational code structure. It integrates with any client or LLM through the model context protocol (MCP).

Its distinguishing feature is an "agent-first tool design" employing robust high-level abstractions rather than low-level concepts like line numbers or primitive search patterns, which enables agents to operate "faster, more efficiently and more reliably, especially in larger and more complex codebases."

Symbol-aware tools are positioned as superior to text-based alternatives because they provide IDE-backed (language-server) semantic understanding. One quoted evaluation: "cross-file renames, moves, and reference lookups that would cost 8–12 careful, error-prone steps collapse into one atomic call." Without precise refactoring tools grounded in code semantics, agents resort to unreliable search-and-replace operations.

## Supported languages

Over 40 languages via language servers, including Ada, AL, Angular, Ansible, Bash, C#, C/C++, Clojure, Dart, Elixir, Elm, Erlang, F#, Go, Groovy, Haskell, Java, JavaScript, JSON, Kotlin, Lua, MATLAB, Nix, OCaml, Perl, PHP, Python, Scala, Ruby, Rust, Swift, TypeScript, YAML, Zig. Scala is listed.
